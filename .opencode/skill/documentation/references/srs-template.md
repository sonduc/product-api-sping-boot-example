# SRS Template

## When to load

Load to write an SRS at `docs/domains/{domain}/srs.md` (+ `srs.vi.md`).

## Template (bilingual EN + VI)

```markdown
# Software Requirements Specification — {Domain}

## 1. Introduction
## 2. Actors
## 3. Functional requirements (FR-xx)
## 4. Non-functional requirements (NFR-xx)
## 5. Business rules
## 6. Data requirements
## 7. Constraints
```

## Notes

- EN in `srs.md`, Vietnamese in `srs.vi.md`.
- The `.vi.md` carries `source`, `source-hash`, `last-synced` metadata.
