# Feature Doc Template

## When to load

Load to write a feature doc at `docs/domains/{domain}/features/{feature}.md`.

## Template

```markdown
# {Feature name}

## Purpose
## Scope
## Data model (entities + fields)
## Endpoints
| Method | Path | Description | Auth |
## Business rules
## Edge cases
## Dependencies (other features/services)
## Related docs
- data-model.md
- flows/{flow}.md
```

## Notes

- EN in `{feature}.md`, Vietnamese in `{feature}.vi.md` (with `source-hash`).
